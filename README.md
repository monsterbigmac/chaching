# ChaChing
個人記帳 webapp

### 使用技術
 - 後端：JAVA / Spring Boot / Spring MVC / Spring Data JPA
 - 前端：JavaScript / Vue3
 - 部署：Nginx / Docker

### 功能
 - 帳務新增查詢修改刪除（CRUD）
 - 帳務分類
 - 權限
